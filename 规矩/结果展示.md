# 结果展示规矩（小柒定，长期有效）

## 状态
- 每个模块的结果都写清状态：成功 / 无数据 / 不完整 / 失败（附原因）。另有“未运行”（例如没勾查询范围）。
- 读不到就是“失败”，绝不报成 0；页面总数和实际读到的条数不一致，就标“不完整”。
- 出错时一句话说明：哪个模块 → 哪一步 → 原因 → 建议。

## 在哪里显示
- 每个模块的结果**一定**显示在窗口里。
- 发不发飞书是每个模块自己的开关；另有“运行完自动发到飞书”勾选框，和每个结果下面的“发到飞书”按钮（点了先确认）。这两个功能不能删。
- 同时在电脑上存一份；明细长时存 Excel。

## 按模块类型显示，不硬套一个模板
- 数量表（待审核 / 待拣货 / 待增值）：行 = 日期（起点到今天）+ 合计，列 = 各区 + 仓库合计；数字右对齐，合计行加粗；同一页的表用同一套列格子，各列上下对齐。
- 区域 + 单号（无任务包裹）：各区数量总览，点一个区看它的单号，可一键复制；复制出来是整齐的文字表（标题行 + 序号<Tab>单号）。
- 任务 + 面单（转寄退货任务）：左边任务清单，右边按佐川面单顺序显示；地址、邮编**按读到的原样显示**，可疑的地方标橙色，下面另起一行写“建议”，绝不改原数据。
- 新模块先想清楚属于哪一类，再复用那一类的显示方式；都不合适时，先问小柒。

## 表格和复制
- 小柒要复制的东西（单号等）一格一个，格子里不放别的。
- 飞书卡片用表格；卡片放不下时拆成几张（标 1/2），绝不丢数据。
- 设计表格时用多个区的真实数据测（C、F 或 A 到 F 全部），不只测 D、E 区。

## 测试
- 测试结果只在仓库助手窗口里看，**不往飞书发测试卡片**。
- 转寄退货任务的测试只用本地 `测试数据\`，不再去飞书读。
