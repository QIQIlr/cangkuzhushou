# 界面规矩（小柒 2026-10-25 定，长期有效）

仓库助手所有看得见的东西（现有页面、新模块、设置、登录、导入导出、插件、所有弹窗和提示）都按 `设计规范\仓库助手设计规范.md` 做（CLAUDE.md 已经把全文读进来了）。

## 最容易忘的几条
- 设计语言只有一种：苹果 iOS 风格（Apple HIG）。浅灰底 + 白色圆角分组列表（像 iPhone“设置”）、绿色开关、胶囊按钮、多选用行尾蓝色 ✓。窗口外壳和标题栏保持 Windows 原样。
- 全软件只用 微软雅黑 UI 一种字体，单号、数字也一样，不用等宽字体。
- 颜色、字号、圆角、间距只从 `公共\界面\主题.py` 取；零件只用 `公共\界面\样板页.py` 里有的。零件不够时，先按规范补零件、写回规范，再用。
- 自动排版：任何窗口宽度都**不出现左右滚动**。放得下就完整并排，放不下就上下排；同一行的块一样宽一样高；同一页白框一样宽、左右对齐；一组小格子每行个数随宽度变。
- 详情区只有一个滚动条，不框里套框。滚动条是悬浮细条，出现时内容宽度不变。
- 弹窗都在主窗口里面弹出，取消在左、主操作在右；每页最多一个蓝色主按钮。
- 不做毛玻璃、弹跳、复杂动画；不用彩色 emoji 当图标，状态只用 ● 圆点 + 状态色。
- 只改样子时，不改模块的查询逻辑。

## 交给小柒前的验收清单（每次改界面都要做）
1. 至少用两种窗口宽度（最大化 + 缩到较窄）截图，确认没有左右滚动、没有被截断的字、白框对齐。
2. 用多个区的真实数据（不只是 D、E 区）看表格，区多的时候也不能挤坏。
3. 对照规范逐条检查颜色、字体、圆角、按钮级别、弹窗样子；有对不上的先改。
4. 启动和切换页面时不能闪出空白小窗口。
5. 截图放进回复，说明“对照规范检查了哪些、还有什么没做”。
