# 仓库助手设计规范（iOS 风格）

v1.6 · 2026-10-31 · 小柒选定（嘴替线程）· 参考图：`设计规范/参考图_工作台.png`

> **一条总规矩：** 仓库助手里所有能看到的东西，包括现有页面、以后的新模块、设置、账号登录、导入导出、插件、各种弹窗和提示，都按这份规范做。新东西做好后要对照本规范检查，并截图给小柒看。

设计来源：苹果的界面规范 Apple Human Interface Guidelines（简称 HIG，iPhone、iPad 和 Mac 的设计规矩）。我们只借它的"样子"，窗口外壳仍是 Windows。

---

## 1. 两处例外

| 例外 | 原因 |
|---|---|
| 主窗口的标题栏和右上角的最小化/最大化/关闭按钮，保持 Windows 原样（弹窗不再例外，v1.3 起改为窗口内弹窗，见第 6 节） | 自己画窗口边框容易出问题，违背"稳定第一" |
| 飞书卡片 | 长什么样由飞书决定，不在本规范范围 |

## 2. 整体感觉

- 浅灰底，内容放在白色大圆角块里（iOS "设置"的分组列表）。
- 一个主色（蓝），状态色只用来表示状态，不拿来装饰。
- 留白多，层级靠字号和灰度区分，不靠线框和阴影。
- 不做毛玻璃、弹跳、复杂动画。

**状态色（结果状态专用，含义固定）：**

| 状态 | 色值 | 说明 |
|---|---|---|
| 成功 | #34C759 绿 | |
| 无数据 | #8E8E93 灰 | 查到了，确实是 0 / 没有 |

## 4. 字

- 字体：全软件只用微软雅黑 UI（Microsoft YaHei UI）一种字体，包括单号、电话、数字，不换成 Consolas 等等宽字体（v1.3 改：小柒反馈混用字体粗细不一致）；需要数字对齐时用表格右对齐。不另装字体（苹果字体按规定只能在苹果设备上用，未逐条核实授权，所以不用）。

| 级别 | 字号 / 粗细 | 用在哪 |
|---|---|---|
| 大标题 | 26px 加粗 | 页面顶部（如"下午好，小柒"） |
| 标题 | 20px 加粗 | 右侧面板标题、弹窗标题 |
| 行标题 | 15px 半粗 | 模块名、列表行主文字 |
| 正文 | 14px 常规 | 一般文字、按钮 |
| 说明 | 12px 常规，次要字颜色 | 描述、时间、分组小标题、底部提示 |
| 大数字 | 20px 半粗 | 结果页里的数量（各区数量、清单右边的数字） |
| 卡片数字 | 26px 半粗，后面跟 12px 灰色单位（单 / 个 / 条；“没查到”不带单位） | 工作台模块卡片右侧的数量（v1.5） |
| 字段名 / 字段内容 | 13px 灰 / 15px 黑 | 明细里的"标签 + 内容"（如 住所、氏名），全软件只用这一对，不单独放大缩小 |

- 字号只从上面这几档取（程序里 `主题.字号`），代码里不直接写 `font-size:15px` 这样的数字；要新的一档，先加进 `主题.字号` 和本表（v1.5）。

## 5. 形状和间距

- 圆角：分组块 / 弹窗 12px；按钮做成胶囊形（圆角 = 高度一半）；输入框 8px；小标签 6px。
- 间距只用这几个值：4 / 8 / 12 / 16 / 20 / 24px。
- 列表行：高度至少 44px，左右内边距 16px。
- 最小窗口 1000×640：这个尺寸下工作台的模块列表要完整显示全部模块，不能有要滚才看得到的行（模块多到实在放不下时才出滚动）。安全网会检查（v1.5）。
- 工作台有模块上次没跑成时，只在"模块 · 共 N 个，已启用 M 个"这一行右侧显示一个橙色文字按钮（⚠ N 个上次没跑成），点开弹窗看详情；**不单独占一块高度**，最小窗口下 5 个模块仍要全部看得见（v1.6）。
- 不用线框分组，不用阴影（开关的小圆钮除外）。

## 6. 零件长什么样

程序里的位置：`公共\界面\组件.py`（分组块、行、勾选行等）、`公共\界面\提示.py`（提示框）。

**页眉（每页最上面）**：灰色小字（日期等）+ 大标题，右上一排按钮；副标题**独占一整行**（跨整行宽），右上按钮跨三行垂直居中。窄窗口下副标题不许被挤成窄长条——折行会顶掉下面模块列表的高度（v1.6）。

**导航（左侧栏）**：一行一个，选中的那行整行蓝底白字、圆角 8px；"设置"放最下面。可收起：收起只剩图标（约 60px），展开显示图标 + 文字（约 200px），顶部 ☰ 切换，记住上次状态；进入结果页自动收起，离开结果页（回工作台、运行记录、设置）自动展开；手动点过 ☰ 之后以手动为准，这次打开期间程序不再自动收或展；收起时鼠标停留显示文字提示。

**分栏视图（看结果、看明细的标准版面，苹果"邮件/备忘录"式）**：左 图标导航 → 中 清单（每行 状态圆点 + 名字 + 一行小字 + 数字）→ 右 详情占满剩余空间。详情区**只有一个滚动条**，不在里面再套小滚动框，不"框里套框"，分区一律用分组列表。以后凡是"先选一项、再看详情"的界面（含新模块、导入导出、运行记录）都用它。清单里选中的行整行蓝底白字，和导航一致。

**自动排版（v1.4，结果页和所有内容区都适用）**：任何窗口宽度都**不出现左右滚动**，只上下滚动。多张表、多块内容放在自动换行的格子里：放得下就完整并排，放不下就换行上下排；同一行的块一样宽一样高；上下排时每块都占满整行，**同一页的白框永远一样宽、左右边缘对齐**，内容少的块只调整里面的列宽或间距（表格：同一页所有表用同一套列格子 = 日期列 + N 个等宽区列（N 取本页区最多的表）+ 合计列；区少的表从左往右填、多余格子留空，所以各列上下对齐）。一组相同的小格子（如单号）每行个数跟着宽度变，同一页里所有组用同一个每行个数，上下对齐。

**运行状态条**：页面顶部一行：状态文字 + 细蓝进度条（拉满剩余宽度）+ 百分比（完成时 100%）+ "运行过程 ›"（点开才显示详细过程）。不写多余的解释句。进度条平滑前进，不按模块一下跳一大段：按各模块历史用时分段，每段里慢慢走，最多走到这一段的 95%，模块做完再补满；出错停在原地并写原因。

**分组列表（最重要的零件）**：灰色小字分组标题（在块外面、左对齐）→ 白色圆角块 → 行与行之间细分隔线 → 块下面可以跟一行灰色说明。模块列表、设置项、运行记录都用它。

**模块行**：开关在左，中间是模块名 + 一行描述 + 一行灰色的"范围 · 是否自动发"，右边是卡片数字 + 单位 + "● 成功 · 时间"，最右一个浅灰 ›。行高 80px。拖动排序照旧可用；拖动把手用浅灰 ≡，不抢眼。打开软件时默认选中第一个模块，右边直接显示它的设置。模块列表下面只放一行脚注（v1.5）。

**错误块（结果页的“卡在哪一步 / 原因 / 怎么办”）**：状态色淡底，最宽 640px、靠左，窄窗口时跟着变窄、字换行（v1.5，例外：不和同页白框一样宽，因为一行字太长读不动）。

**找单号**：单号很多的页面，在“各区数量”那一行右边放一个输入框（宽 220），输入完整单号或后几位回车：跳到那一格、选中并复制；这次结果里没有就把框标红，状态栏说明（v1.5）。

**复制按钮**：点了以后按钮自己变成“已复制 ✓”1.5 秒再变回来（v1.5）。

**按钮（三级）**：
- 主按钮：蓝底白字胶囊，**每个页面或弹窗最多一个**（如"运行已启用模块"）。
- 次要按钮：#E5E5EA 底、蓝字胶囊（如"只运行选中的"）。
- 文字按钮：只有蓝字（如"打开 Excel""发到飞书"）。
- 危险操作（将来如果有）：红字。

**开关**：iOS 样式，开是绿色。

**滚动条**：iOS/macOS 式悬浮细滚动条：盖在内容上、不占宽度；平时隐藏或很淡，鼠标在区域上或滚动时显示；约 6px 宽、圆头、半透明灰。滚动条出现与否，内容宽度不能变。全软件只用这一种。程序里：公共\界面\滚动条.py。

**角标**（如"成功""1 条要看"）：胶囊形，状态色淡底 + 同色字 + 圆点，高度、圆角、字号全软件一致：高 22、圆角 11。

**设置行里的操作按钮**：小号灰底（#E5E5EA）蓝字胶囊，右对齐、垂直居中；不用光秃秃的蓝字。程序里：按钮 kind = small；危险操作的红字胶囊 kind = dangerpill。

**分组块、行、勾选行**：分组块 = 白色圆角块；行 = 块里的一行；勾选行 = 能选的行，选中的行末尾显示蓝色 ✓。

**多选**：用勾选行，不用方框勾选框。

**单选 / 切换几种视图**：iOS 分段控件（灰色轨道，选中那段白底）。

**输入框**：白底，放在分组块的一行里，灰色提示字；出错时下方一行红色说明。

**表格（结果页的数量表、单号表）**：放在白色圆角块里；表头是灰色小字、不加底色；行间细分隔线；数字右对齐；合计行加粗。

**结论条（结果页顶部）**：模块名 + 状态角标 + 一句话结论；不完整 / 失败时，结论那句话用状态色文字，整条不铺淡底（v1.5 改：状态色只用在角标、圆点、结论那句话、错误块 / 提醒块的底，不拿整条结论条做装饰）。出错时，提醒（如“E区 没查到（不是 0）”）并进错误块，在细线下面；只有提醒、没有出错时，提醒单独一块橙色淡底。

**进度**：细的蓝色进度条 + 一行灰字写当前步骤。

**弹窗（所有确认、提示、登录、选择任务、改名出错、更新数据等）**：
- 在主窗口里面弹出（不用 Windows 自带的带标题栏小窗）：主窗口盖一层半透明暗色，中间白色圆角卡片（12px），标题 17px 加粗居中，说明文字居中。
- 底部按钮用胶囊按钮、等宽并排，取消在左、主操作在右：主操作 = 蓝底白字；次操作/取消 = 灰底蓝字；危险操作 = 红字。Esc = 取消，回车 = 主操作。
- 全软件只用这一个弹窗零件。程序里：公共\界面\提示.py。
- 需要用户勾选、输入的弹窗（如选择任务、登录 WMS），里面也用分组列表。
- 所有确认和提示都用统一的提示框：取消在左，主操作在右并加粗；危险操作红字；直接关窗口等于取消。
- （v1.3 取消原「弹窗边框保持 Windows 原样」的例外：窗口内弹窗是主窗口里的一层，不用自己画窗口边框，没有那个风险。）

**空状态**（还没有结果、没有记录）：区域中间一行灰字说明，可加一个浅灰图标。

**图标**：统一用同一套线条风格的简单符号，同一大小、同一颜色（次要字灰或主色蓝）；状态只用 ● 圆点。不混用彩色 emoji。

## 7. 组件样板页（v1.3 新增）

- 程序里有一个"界面样板"页，把上面每个零件各放一份。每个零件对照苹果官方资料做：Human Interface Guidelines https://developer.apple.com/design/human-interface-guidelines ，Apple Design Resources https://developer.apple.com/design/resources/ 。本规范和官网对不上时，以官网修正本规范。
- 样板页经小柒确认后，所有页面只用样板页里的零件，不在页面里另写样式。程序里：公共\界面\样板页.py（设置 → 界面样板），是零件的唯一来源。

## 8. 以后新增东西时怎么用

- 新模块、新设置、登录、导入导出、插件：先从上面的零件里挑，拼起来；零件不够时，先按本规范的颜色、字号、圆角补一个新零件，**写回本规范**，再用。
- 所有颜色、字号、圆角都从程序里那一份统一样式取，不在单个页面里另写。
- 每次做完，截图对照本规范检查；交给小柒看时附截图。
