# ===== 无任务包裹 飞书消息格式 =====
# 以 # 开头的行是说明，不会发出去。改完保存即可，下次查询就用新格式。
#
# 分段（每个标记单独一行）：
#   [开头]        消息最上面
#   [每个区域]    每个区域写一段（D区一次、E区一次）
#   [没有包裹时]  某个区域 0 个时用这段代替 [每个区域]；删掉这段就照样用 [每个区域]
#   [查询失败时]  某个区域没查成时用这段
#   [结尾]        消息最下面
#   [设置]        单号分隔=换行（还可以写 逗号、顿号、空格、斜杠，或者直接写想用的符号）
#
# 可以用的内容：
#   任何地方：{日期} {时间} {合计} {状态} {用时}
#   区域段里另外可以用：{区域} {数量} {单号列表}（区域段里的 {状态} 是这个区域自己的状态）
#
#   想要空一行：单独一行写 {空行}（每段前后直接留的空行只是为了好看，不会发出去）
# 换完内容后变成空的行会自动去掉（例如 0 个时 {单号列表} 那一行）。
# 出错时，“哪一步出错、原因、建议、日志文件夹名”会自动加在最后，不用写在这里。

[开头]
📦 {日期} 无任务包裹（共{合计}个）
{空行}
[每个区域]
{区域} {数量}个：{单号列表}
[没有包裹时]
{区域} 无
[设置]
单号分隔=逗号
