# ===== 飞书任务明细：关键词对照表 =====
# 程序不“理解”内容，只按这张表一个字一个字地比对任务描述里每一行“名称：内容”的名称。
# 依据：2026-10-24 普查“我负责的”59 条任务（未完成 14 + 已完成 45），表里每种写法都真实出现过。
#
# 写法：一行一项，“输出项 = 写法1、写法2、……”。以 # 开头的行是说明。
# 比对前先统一：去掉空格；名称以【开头的去掉【】；名称后面括号里的说明去掉
#   （如“退货方式（寄付/到付/上门取件）”→“退货方式”，“购物订单截图【10398转寄服务费】”→“购物订单截图”）；
#   繁体“電話”当作“电话”。
# 以后出现新写法：结果里会有 ⚠“不认识的项目”，在对应的行后面加上这个写法即可，不用改程序。
# 改之前程序会自动存版本（Git），改错了能退回。
