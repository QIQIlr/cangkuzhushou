# 安全网说明（小柒 2026-10-28 定）

安全网 = 每次改完程序都跑一遍的检查，确认三件事：**没让改的地方没有变、5 个模块算得对、显示得对**。
它不连 WMS、不开浏览器、不发飞书，只用临时复制的设置和编造的假数据；真实的 `模块参数.json`、`模块设置.txt`、`日志\运行总表.csv` 不会被动（跑完会核对）。

## 怎么跑（一条命令，约 1 分钟）

```
.venv\Scripts\python.exe 自测\安全网.py
```

## 结果怎么看

- 打开 `自测\安全网结果\报告.txt`，**第一行就是结论**：“全部通过”或“没通过：N 项”，下面列出没通过的是哪几项、原因是什么。
- 退出码：0 = 全部通过，1 = 有没通过的。
- 这次的截图在 `自测\安全网结果\截图\`；**和基准不一样的页面**，前后对照图在 `自测\安全网结果\对照\`：左边是基准（小柒认可的样子），中间是现在，右边黑底上亮的地方就是变了的地方。

## 检查了什么

1. **原有的回归测试**（`自测\回归测试.py`）：设置文件保护、查询范围、改名、飞书开关、运行流程、上次结果等，全部要过。
2. **模块检查**：5 个模块，用假数据（和 `测试数据\` 里的真实转寄任务）把“结果计算 → 组成消息 → 结果页”走一遍，检查状态和数字：
   - 待审核 / 待拣货 / 待增值：成功、全是 0、一格没查到（不完整，合计“N+”）、全没查到（失败，不是 0）、区很多（三张表）；另外检查“往前查”的规则。
   - 无任务包裹：成功、无数据、一个区没查到（不完整，查到的单号照常显示）、全没查到、区很多（6 个区）、单号很多（600 个一个不丢）。
   - 转寄退货任务：成功、无数据、不完整、失败；`测试数据\` 的真实任务全部能整理。
   - 每种结果页都要画得出来、没有左右滚动。
3. **截图**：工作台、运行结果（9 种结果）、运行记录、设置、界面样板、5 个弹窗，每个都截 **宽 1600×900** 和 **窄 1000×640** 两张，检查没有左右滚动。
4. **和基准比较**：每张截图和 `自测\基准截图\` 里同名的那张逐个像素比，不同的像素超过 0.1% 就算“变了”。

截图里的时间、问候语、运行记录、设置都是固定的（`自测\基准数据\`），所以程序没变时，每次截出来都一模一样。截图只用编造的数据（没有真实客户的姓名、地址、电话）。

## 有页面变了怎么办

- **这次本来就要改这一页**（小柒要求的）：正常。把对照图给小柒看，小柒说“可以”以后再更新基准（见下面）。
- **这次没让改这一页**：说明改动碰到了别的地方，**先修好**，再跑一遍，直到这一页和基准一样。
- 安全网没有全部通过，不能说“做好了”。

## 什么时候更新基准

**只有小柒确认了新样子以后才更新**，命令是：

```
.venv\Scripts\python.exe 自测\安全网.py --更新基准
```

它会把这次的截图存成新的基准（`自测\基准截图\`，进 Git，可以退回）。
加了新页面、新弹窗、新模块的结果样子时：在 `自测\安全网.py` 的 `截全部()` / `截图场景()` 里加上，小柒确认后用 `--更新基准` 收进来；加新模块时在 `模块检查()` 里加它的几种结果。
