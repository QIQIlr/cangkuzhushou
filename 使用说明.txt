【仓库助手 使用说明】（这里不放账号、密码、Webhook）

一、怎么打开
  双击 仓库助手（测试版）.vbs → 直接出窗口，没有黑框。

二、窗口怎么用
  左边：模块列表。勾选 = 启用；拖动或点 上移/下移 调顺序；改动自动保存。
    “运行已启用模块”：按顺序跑所有打勾的模块。
    “只运行选中的模块”：点选一个或按住 Ctrl 选几个，没打勾的也能跑。
    每个模块的设置：选中模块 → 点“⚙ 设置（名字、区域等）”或双击模块：名字、查询区域/查询范围、结果发到飞书。
    改名：在设置最上面的“名字”框里改，点保存。窗口、飞书卡片、Excel、日志都会用新名字；
      勾选、顺序和其他设置不变。“恢复原名”= 改回原来的名字。鼠标停在改过名的模块上会显示原名。
      原名是固定的（下面第三部分和 模块清单.md 里写的都是原名），跟 Claude 说新名字、原名或只说功能都行。
  右边：进度、运行过程、结果。运行过程和结果之间的分隔线可以拖动。
    结果：每个模块一页，点上面的标签切换。标签上 ✔ 正常、⚠ 不完整或有要看的地方、✖ 失败、○ 没有数据，后面是主要数字。
      每页从上到下：一行结论 → 出错时红框（卡在哪一步、原因、怎么办），要看的地方橙框 → 内容 →
      最下面一行（飞书发了没有、发到飞书、打开 Excel、打开这次的日志）。
      内容有三种样子：数量表（待审核、待拣货、待增值；待拣货可切换 合计 / 合箱 / 单箱）、
      区域和单号（无任务包裹：左边点区，右边看单号）、任务和面单（转寄退货任务）。
      复制：数量表单击一格后 Ctrl+C 或双击；单号双击复制一个，按住 Ctrl 选几个再 Ctrl+C，或点“复制 X区 全部单号”。
  下面：设置飞书、登录 WMS、登录飞书、更新邮编数据、打开日志文件夹、刷新模块列表。
  结果一定会显示在窗口里。“运行完自动发到飞书”勾上 = 按各模块自己的开关自动发；
    不勾 = 只在窗口显示，想发哪个，就点那个结果下面的“发到飞书”（已经发过的会先问一下，避免重复）。
  掉线时会弹窗，在弹出的 Chrome 里登录后点“我登录好了”。运行中关闭窗口会先问你。

三、模块
  每个模块在哪个页面、查什么、输出什么，见 模块清单.md。现在有：
    无任务包裹：已挂起 + 任务小类=无任务的包裹，各区数量 + 转运单号（默认 D区、E区）。
    待审核 / 待拣货 / 待增值（审核 → 拣货 → 增值）：按天列出还没处理的任务，从清空的那天列到今天（默认瑞江仓库）。
  瑞江仓库 = D区 + E区；松户仓库 = A区 + C区 + F区；B区 是测试区。
    飞书任务明细（窗口里现在叫“转寄退货任务”）：手写佐川飞脚便面单时的参照，只在窗口里看，不发飞书。
      读飞书“任务 → 我负责的”。先读全部标题，弹出窗口按飞书里的顺序列出，
      你点一行勾选（可以多选）→“开始读取”→ 逐条读详情。每条约 6～11 秒。
      结果页：左边是读到的任务（类型一行、单号一行，要看的写“⚠ 几处要看”），点一条，右边按面单顺序显示：
        お届け先（邮编、住所、氏名、電話）→ ご依頼主（寄件人）→ 品名（日语品名参考 + 内容物原文）
        → 参考（转运单号、会员码、重量、位置、飞书标题）→ 评论和其他信息（平时收起，点开看）。
        要抄的字大；⚠ 提醒用橙色小字写在那一项下面，最上面一句话说这条有几处要看。
      邮编：按日本邮政官方数据（邮编数据\ 文件夹，离线）查地址的邮编；地址里写了邮编的就核对。
        简体、繁体这类写法差异直接换成日文，不提示；区名、町名找不到或邮编对不上，标 ⚠ 并给出相近写法
        （例如“大阪市里没有‘野生区’，有‘生野区’”）。查不准时不替你填。
        官方每月更新，隔几个月点一次窗口下面的“更新邮编数据”就行（要联网，约 2 MB）。
      品名参考：按 品名对照表.txt 里的关键词给出日语品名（例如 挂画 → タペストリー）；没对上的写“没有参考，请自己填”。
      只读：只用网址打开页面，不点任务、不打字。遇到登录页、验证码、“访问频繁”等提示会立刻停下告诉你。
      描述里项目名称的各种写法在 飞书对照表.txt 里；出现新写法时结果里会有 ⚠，告诉 Claude 加进去。

四、WMS 登录
  WMS 网址：https://wms-admin.rakufun.jp/
  WMS 账号：副账号（主账号小柒自己用；同一账号在别处登录会被挤掉）
  自动化专用 Chrome 配置：C:\1LR\自动化工作流\浏览器配置
    和平时用的 Chrome 分开，登录一次后保持登录。
    要单独登录时点窗口下面的“登录 WMS”，登录完关掉那个 Chrome 窗口。
    运行查询时，这个专用 Chrome 必须先关掉（程序会提醒）。

四之二、飞书网页版登录（飞书任务明细用）
  和 WMS 用同一个自动化专用 Chrome。掉线时程序会报“需要登录飞书”：
  点窗口下面的“登录飞书” → 在弹出的 Chrome 里扫码或输入账号登录 → 看到任务列表后关掉那个 Chrome → 再运行。

五、飞书群机器人
  点窗口下面的“设置飞书” → 粘贴 Webhook 地址 → 填自定义关键词 → 点“测试并保存”。
  测试消息发成功才保存（保存在 密钥.env，不用自己去找这个文件）。换群或换机器人时重新设置即可。
  每个模块单独发一张卡片表格；单号很多时自动拆成几张（标 1/3、2/3……），不会丢单号。

六、文件夹里的东西
  仓库助手（测试版）.vbs   双击打开窗口
  使用说明.txt            就是这个文件
  模块清单.md             每个模块的步骤、输出、核对状态
  模块设置.txt            模块的顺序和开关（窗口里改，一般不用手改）
  模块参数.json           每个模块的设置（窗口里改）
  密钥.env                飞书 Webhook 等，只在这台电脑上，不要发给别人
  飞书对照表.txt          飞书任务明细认项目名称用的关键词表
  品名对照表.txt          内容物 → 日语品名参考的关键词表（可以自己加）
  邮编数据\               日本邮政官方邮编数据（点“更新邮编数据”会更新）
  测试数据\               测试用的真实数据（只在这台电脑上，不进版本记录）
  模块\                   每个模块一个文件
  公共\                   各模块共用的部分和窗口程序
  日志\                   每次运行的记录，说明见 日志\说明.txt；超过 90 天自动删除
  浏览器配置\             自动化专用 Chrome 的登录状态
  工具\ .venv\            Python、Git 和程序要用的组件
  设置备份\               模块设置.txt 的自动备份

七、出问题时
  把飞书卡片下面的错误说明（或窗口里的结果）和日志文件夹名发给 Claude 就行，Claude 会自己到电脑上看日志。
