【仓库助手 使用说明】（这里不放账号、密码、Webhook）

一、怎么打开
  双击 仓库助手（测试版）.vbs → 直接出窗口，没有黑框。

二、窗口怎么用（2026-10-24 整体改版；2026-10-25 换成 iOS 风格，规范见 设计规范\仓库助手设计规范.md）
  最左边最上面的 ☰ = 收起 / 展开菜单。收起后只剩图标（鼠标停在图标上会显示名字），会记住你上次点的样子。
    进“运行结果”时菜单会自动收起，把地方让给结果；你手动展开过，这次打开期间就不再自动收。
  左边是导航：工作台、运行结果、运行记录，最下面是设置。

  工作台（打开就是这一页）
    模块卡片：一张卡片一个模块，从上到下就是运行顺序。
      开关 = 启用（打开的才会在“运行已启用模块”时跑）；拖动卡片或点右上角 ↑ ↓ 调顺序；改动自动保存。
      卡片上写着：做什么、查询范围、跑完会不会自动发飞书，右边是上次运行的结果（数字、状态、时间）。
        飞书那个小标签写的是最终结果：“跑完自动发飞书” / “不自动发” / “只在窗口看”（这个模块不能发）。
    右上角：“跑完自动发飞书”总开关、“只运行选中的”、“运行已启用模块”（蓝色）。
      “运行已启用模块” = 按顺序跑所有打开的模块；“只运行选中的” = 点选一个或按住 Ctrl 选几个，没打开的也能跑。
    飞书怎么发（2026-10-24 起）：总开关开着，并且这个模块自己的“跑完自动发到飞书群”也开着，跑完才自动发；
      两个里有一个关着就不自动发。工作台最下面一句话会写清这次跑完哪些模块会自动发。
      不管开关怎样，都可以在结果下面点“发到飞书”手动发一次（已经发过的会先问一下，避免重复）。
    右边：点一个模块，就显示它的设置。改了马上保存，没有“保存”按钮（下面一行会写“✔ 已保存”）。
      名字：在左边卡片上双击粗体名字，就在原地改（回车或点别处保存，Esc 不改）；
        也可以点右边的名字或铅笔改，两边改的是同一个名字。想改回原来的名字，就填原名。双击卡片别的地方不会做什么。
        改名后窗口、飞书卡片、Excel、日志都用新名字；勾选、顺序和其他设置不变。
        原名是固定的（下面第三部分和 模块清单.md 里写的都是原名），跟 Claude 说新名字、原名或只说功能都行。
      跑完自动发到飞书群：这个模块自己的开关（见上面“飞书怎么发”）。
      查询范围（待审核、待拣货、待增值、无任务包裹）：可以勾仓库，也可以勾单独的区，每勾一项单独出一张表。
        勾了仓库，它包含的区就收起来（例如勾了瑞江仓库，D区、E区 不用再勾）。两个仓库可以一起勾。
        也可以一项都不勾：这时这个模块即使在左边开着，运行时也不跑，结果里写“没有勾选查询范围，这次没有运行”。
    需要注意：上次运行有问题的模块会列在这里，没有就不显示。

  运行结果（点运行后自动切过来）
    最上面一行：● 状态、进度条（按每个模块平时要多久慢慢往前走）、当前步骤；“运行过程 ›”点开看逐行记录；
      跑完可以“打开这次的日志”。
    中间：这次跑的模块和状态（等待、正在运行、成功、无数据、不完整、失败），后面是主要数字。
      每个模块查完马上就能点开看完整结果（也马上按设置发飞书），不用等后面的模块。
      跑完会先选中有问题的那个；如果你中途自己点过哪个，就不会把你跳走。
    打开仓库助手时，这一页显示上一次运行的结果，最上面写着是几点跑的（不是现在的数字，要最新的就再运行）。
      只留最近一次，存在 日志\上次结果.json（只在这台电脑上），下次运行时换掉。
    右边：选中模块的结果，整块只有一个滚动条。从上到下：模块名和状态、一句结论 → 出错时红色淡底（卡在哪一步、原因、怎么办），
      要看的地方橙色淡底 → 内容 →
      最下面一行（飞书发了没有、发到飞书、打开 Excel、打开这次的日志）。
      内容按模块类型不同：数量表（待审核、待拣货、待增值；待拣货可切换 合计 / 合箱 / 单箱）、
      区域和单号（无任务包裹：上面是各区数量总览，下面每个有单号的区一块，单号排成格子）、任务和面单（转寄退货任务：左边任务小清单，右边按面单顺序分块，
      收件人一块、寄件人和品名一块、参考一块，评论平时收起；要看的字段是橙色字）。仓库两张表放得下就并排。
      复制：数量表单击一格后 Ctrl+C 或双击；单号双击复制一个，按住 Ctrl 选几个再 Ctrl+C，或点每个区右边的“复制 X区 全部”，几个区时还有“复制全部区”。

  运行记录：每次运行一行（时间、模块、状态、数量、用时、问题），上面可以按模块筛选；双击一行打开那次的日志。
    灰色、名字后面写“（测试）”的是 Claude 测试时跑的，工作台的“上次结果”不算它们。

  设置：设置飞书、登录 WMS、登录飞书、更新邮编数据、打开日志文件夹、刷新模块列表。
    “跑完自动发飞书”的开关只在工作台右上角，设置页里只写说明。

  结果一定会显示在窗口里。掉线时会弹窗，在弹出的 Chrome 里登录后点“我登录好了”。运行中关闭窗口会先问你。
三、模块
  每个模块在哪个页面、查什么、输出什么，见 模块清单.md。现在有：
    无任务包裹：已挂起 + 任务小类=无任务的包裹，各区数量 + 转运单号（默认瑞江仓库 = D区 + E区；也可以按仓库或单独的区选）。
    待审核 / 待拣货 / 待增值（审核 → 拣货 → 增值）：按天列出还没处理的任务，从清空的那天列到今天（默认瑞江仓库）。
  瑞江仓库 = D区 + E区；松户仓库 = A区 + C区 + F区；B区 是测试区。
    飞书任务明细（窗口里现在叫“转寄退货任务”）：手写佐川飞脚便面单时的参照，只在窗口里看，不发飞书。
      读飞书“任务 → 我负责的”。先读全部标题，弹出窗口按飞书里的顺序列出，
      你点一行勾选（可以多选）→“开始读取”→ 逐条读详情。每条约 6～11 秒。
      结果页：左边是读到的任务（类型一行、单号一行，要看的写“⚠ 几处要看”），点一条，右边按面单顺序显示：
        お届け先（邮编、住所、氏名、電話）→ ご依頼主（寄件人）→ 品名（日语品名参考 + 内容物原文）
        → 参考（转运单号、会员码、重量、位置、飞书标题）→ 评论和其他信息（平时收起，点开看）。
        要抄的字大；⚠ 提醒用橙色小字写在那一项下面，最上面一句话说这条有几处要看。
      邮编：按日本邮政官方数据（邮编数据\ 文件夹，离线）查地址的邮编；地址里写了邮编的就核对。
        简体、繁体这类写法差异直接换成日文，不提示；区名、町名找不到或邮编对不上，标 ⚠ 并给出相近写法
        （例如“大阪市里没有‘野生区’，有‘生野区’”）。查不准时不替你填。
        官方每月更新，隔几个月到“设置”页点一次“更新邮编数据”就行（要联网，约 2 MB）。
      品名参考：按 品名对照表.txt 里的关键词给出日语品名（例如 挂画 → タペストリー）；没对上的写“没有参考，请自己填”。
      只读：只用网址打开页面，不点任务、不打字。遇到登录页、验证码、“访问频繁”等提示会立刻停下告诉你。
      描述里项目名称的各种写法在 飞书对照表.txt 里；出现新写法时结果里会有 ⚠，告诉 Claude 加进去。

四、WMS 登录
  WMS 网址：https://wms-admin.rakufun.jp/
  WMS 账号：副账号（主账号小柒自己用；同一账号在别处登录会被挤掉）
  自动化专用 Chrome 配置：C:\1LR\自动化工作流\浏览器配置
    和平时用的 Chrome 分开，登录一次后保持登录。
    要单独登录时到“设置”页点“登录 WMS”，登录完关掉那个 Chrome 窗口。
    运行查询时，这个专用 Chrome 必须先关掉（程序会提醒）。

四之二、飞书网页版登录（飞书任务明细用）
  和 WMS 用同一个自动化专用 Chrome。掉线时程序会报“需要登录飞书”：
  到“设置”页点“登录飞书” → 在弹出的 Chrome 里扫码或输入账号登录 → 看到任务列表后关掉那个 Chrome → 再运行。

五、飞书群机器人
  到“设置”页点“设置飞书” → 粘贴 Webhook 地址 → 填自定义关键词 → 点“测试并保存”。
  测试消息发成功才保存（保存在 密钥.env，不用自己去找这个文件）。换群或换机器人时重新设置即可。
  每个模块单独发一张卡片表格；单号很多时自动拆成几张（标 1/3、2/3……），不会丢单号。

六、文件夹里的东西
  仓库助手（测试版）.vbs   双击打开窗口
  使用说明.txt            就是这个文件
  模块清单.md             每个模块的步骤、输出、核对状态
  模块设置.txt            模块的顺序和开关（窗口里改，一般不用手改）
  模块参数.json           每个模块的设置（窗口里改）
  密钥.env                飞书 Webhook 等，只在这台电脑上，不要发给别人
  飞书对照表.txt          飞书任务明细认项目名称用的关键词表
  品名对照表.txt          内容物 → 日语品名参考的关键词表（可以自己加）
  邮编数据\               日本邮政官方邮编数据（点“更新邮编数据”会更新）
  测试数据\               测试用的真实数据（只在这台电脑上，不进版本记录）
  模块\                   每个模块一个文件
  公共\                   各模块共用的部分和窗口程序（公共\界面\ 是窗口各页面和统一样子）
  日志\                   每次运行的记录，说明见 日志\说明.txt；超过 90 天自动删除
  浏览器配置\             自动化专用 Chrome 的登录状态
  工具\ .venv\            Python、Git 和程序要用的组件（版本记在 requirements.txt）
  设置备份\               模块设置.txt 和 模块参数.json 的自动备份
  自测\                   Claude 改程序后跑的测试（不连 WMS、不发飞书，你不用管）

七、出问题时
  把飞书卡片下面的错误说明（或窗口里的结果）和日志文件夹名发给 Claude 就行，Claude 会自己到电脑上看日志。

八、换电脑 / 重装时（由 Claude 做，你只要说一声）
  现在用的：Python 3.13.17（在 工具\Python\）、Git（在 工具\Git\），组件版本见 requirements.txt。
  1. 把整个 C:\1LR\自动化工作流 文件夹拷过去（最好放在同样的位置；放别处也行，程序按自己所在的文件夹找东西）。
  2. 装好 Google Chrome（程序会在常见的安装位置找它；找不到时会用中文告诉你）。
  3. 重建 .venv（.venv 里写死了建它时的文件夹位置，拷过去不一定能用）：
       删掉旧的 .venv 文件夹 → 工具\Python\python.exe -m venv .venv
       → .venv\Scripts\python.exe -m pip install -r requirements.txt
     （工具\ 没拷过去时，先装同版本的 Python 3.13.17 到 工具\Python\）
  4. 在“设置”页重新登录 WMS 和飞书（浏览器配置\ 里是登录状态，换电脑后一般要重新登录）、重新“设置飞书”（密钥.env 不进版本记录）。
  5. 邮编数据\ 没拷就点“更新邮编数据”；测试数据\ 要单独拷。
  6. Claude 跑一遍安全网（自测\安全网说明.md），全部通过才算好了。
