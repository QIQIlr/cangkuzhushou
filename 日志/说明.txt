日志文件夹说明（给小柒和 AI 看）
================================

一、每次运行一个文件夹
  名字：日期_时间_模块名，例如 2026-10-22_234911_无任务包裹
  里面可能有：
  - 运行记录.txt   每一步做了什么、成功还是失败、用了几秒；最后一行是结论。先看这个。
  - 发送内容.txt   这次发到飞书的消息原文，以及发送结果（成功 / 失败 / 未知 / 未发送）。
  - 截图.png       出错那一刻的网页截图（只在出错时有）。
  - 网页快照.html  出错那一刻的网页内容，AI 用来判断页面是否改版（只在出错时有）。
  - 技术详情.txt   Python 报错原文、Playwright / Chrome / 系统版本、页面网址（只在出错时有）。

二、运行总表.csv
  每次运行一行：时间、模块、状态、数量、用时、错误摘要、日志文件夹。用 Excel 直接打开。

三、状态的意思
  成功     查到了，数字核对无误
  无数据   页面明确显示“共 0 条记录”
  不完整   读到的条数和页面显示的总数对不上——结果不能全信，请手动核对
  失败     没查成，原因见错误摘要（不会把失败当成 0 报出来）

四、错误类型和该怎么办
  需要登录                       点仓库助手窗口下面的“登录 WMS”登录一次，再重新运行
  页面元素找不到（WMS 页面可能改版） 把飞书消息和日志文件夹名发给 Claude
  网络或超时                     检查网络后重新运行；连续失败就发给 Claude
  数据对不上                     到 WMS 手动核对；反复出现就发给 Claude
  电脑环境问题                   按提示处理（例如先关掉自动化专用 Chrome 窗口）
  程序本身出错                   把飞书消息和日志文件夹名发给 Claude

五、出问题时怎么求助
  把飞书消息（或运行总表里那一行）和“日志文件夹名”发给 Claude 就够了。
  需要时 Claude 会读文件夹里的 运行记录.txt、技术详情.txt、截图.png、网页快照.html。

六、飞书消息
  每个模块单独发一条飞书卡片（带表格）。内容多时拆成几张，标题后面写“（1/3）”等，运行记录.txt 里有一行说明拆了几张。
  出错时“模块 → 步骤 → 原因 → 建议 + 日志文件夹名”写在卡片下方。
  Excel：表格类模块会在本次运行文件夹里另存一份 .xlsx。

七、其他
  - 日志里不写密码、Webhook 地址、cookie。
  - 超过 90 天的运行文件夹会自动删除。
